# NovaSaaS — WordPress theme for SaaS startups

Premium WordPress theme kit for SaaS startups, software companies and tech businesses. Built for **Elementor**, with a dark glassmorphism design, animated hero sections and pricing tables.

Theme folder: [`wp-content/themes/novasaas/`](wp-content/themes/novasaas/) · Version 1.0.0

## Includes
- Templates: `index`, `page`, `single`, `archive`, `search`, `404`, plus `page-templates/`
- `inc/` — theme functions and settings
- `tgm/` — required/recommended plugin installer (TGM Plugin Activation)
- `demo-data/` — importable demo content
- `documentation/` — user guide
- RTL support (`rtl.css`), translation-ready (`languages/`)
- Full build notes: `NOVASAAS_VSCODE_COMPLETE.md.pdf`

## Install
1. Zip `wp-content/themes/novasaas` (or copy it into your site's `wp-content/themes/`).
2. WordPress admin → Appearance → Themes → Activate **NovaSaaS**.
3. Install the plugins it asks for (Elementor etc.), then import the demo data.
