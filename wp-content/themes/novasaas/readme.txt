A premium dark SaaS & startup landing page WordPress theme kit designed for ThemeForest.

== Description ==

NovaSaaS is a premium WordPress theme built for SaaS products, startups, and digital agencies. It ships with a full StreamFlow demo — a fictional project-management SaaS — so you can see exactly how a finished site looks before you customise a single pixel.

Key highlights:

* Dark glassmorphism design system with 60+ CSS custom properties
* 5 ready-made page templates: Home, Features, Pricing, About, Contact
* Fully compatible with Elementor Page Builder
* One-Click Demo Import powered by OCDI
* WordPress Customizer with 7 panels (colors, typography, header, hero, footer, blog)
* Vanilla JavaScript — no jQuery dependency
* RTL language support (Arabic, Hebrew, Persian, Urdu)
* Translation ready (.pot file included)
* WCAG 2.1 accessibility — keyboard navigation, skip links, ARIA roles
* Mobile-first responsive from 320 px to 1920 px
* Schema.org breadcrumbs
* Child-theme compatible

== Installation ==

1. In your WordPress dashboard, go to Appearance > Themes > Add New > Upload Theme.
2. Upload the novasaas.zip file.
3. Click "Install Now", then "Activate".
4. Follow the prompts to install required plugins (Elementor, One Click Demo Import).
5. Go to Appearance > Import Demo Data and click the StreamFlow demo preview to import.

For a manual installation via FTP:

1. Unzip novasaas.zip to your /wp-content/themes/ directory.
2. Log in to your WordPress dashboard, go to Appearance > Themes.
3. Activate NovaSaaS.

== Frequently Asked Questions ==

= How do I import the demo content? =

Install and activate Elementor and One Click Demo Import. Then go to Appearance > Import Demo Data and click the StreamFlow demo image to start the import.

= Can I use the theme without Elementor? =

Yes. The theme includes five standalone PHP page templates that work without Elementor. Elementor is required only to replicate the demo visuals exactly.

= Is NovaSaaS compatible with WooCommerce? =

Yes. The theme declares full WooCommerce support including product gallery zoom, lightbox, and slider.

= Does NovaSaaS support RTL languages? =

Yes. The rtl.css file provides full right-to-left layout overrides.

= How do I create a child theme? =

Create a new folder in /wp-content/themes/ (e.g. novasaas-child), add a style.css with a "Template: novasaas" header, and a functions.php that enqueues the parent stylesheet.
