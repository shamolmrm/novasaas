NovaSaaS Documentation

Premium dark SaaS & startup landing page WordPress theme kit. Full reference for installation, customization, and advanced usage.

Requires WP: 6.2+ Requires PHP: 8.0+ License: GPLv2+ ThemeForest: Extended / Regular

Introduction

NovaSaaS is a purpose-built WordPress theme for SaaS companies, startups, and digital agencies. It ships with a complete demo — StreamFlow, a fictional project-management SaaS — so you can see a finished site before touching a single setting.

The theme is built entirely without jQuery, uses PHP 8 OOP patterns, and follows WordPress Coding Standards throughout. Every feature is accessible, keyboard-navigable, and mobile-first.

What's included

  • 5 page templates: Home, Features, Pricing, About, Contact
  • Full blog: archive, single post, search, 404
  • WordPress Customizer with 7 sections
  • AJAX contact form with rate limiting
  • One-Click Demo Import integration
  • RTL stylesheet & translation POT file
  • Complete documentation (this file)

Installation

Method A — WordPress Dashboard (recommended)

  1. Upload the theme

    Go to Appearance > Themes > Add New > Upload Theme. Select novasaas.zip and click Install Now.

  2. Activate

    Click Activate on the success screen.

  3. Install required plugins

    A notice will appear at the top of the dashboard. Click Begin installing plugins and install Elementor and One Click Demo Import.

  4. Install TGM Plugin Activation library

    Download class-tgm-plugin-activation.php from github.com/TGMPA and replace the stub file at tgm/class-tgm-plugin-activation.php.

Method B — FTP / SFTP

  1. Unzip novasaas.zip on your computer.
  2. Upload the novasaas/ folder to /wp-content/themes/ via FTP.
  3. In the dashboard, go to Appearance > Themes and activate NovaSaaS.

Demo Import

Important: Perform the demo import on a fresh WordPress installation to avoid overwriting existing content.

  1. Activate required plugins

    Elementor and One Click Demo Import must both be active.

  2. Go to Import Demo Data

    Navigate to Appearance > Import Demo Data.

  3. Select StreamFlow demo

    Click the preview image labelled StreamFlow — Main Demo.

  4. Wait for import to complete

    The importer will load content, widgets, and customizer settings. This takes 1–3 minutes. Do not close the browser tab.

  5. Done

    Visit your site's front page. The StreamFlow demo should be visible. Go to Appearance > Customize to replace placeholder text and colors with your own branding.

If you get a timeout, add set_time_limit(300); to your wp-config.php and retry.

Fonts

The theme loads Plus Jakarta Sans (headings) and Inter (body) from Google Fonts. Both can be changed from the Typography section in the Customizer.

Menus

The theme registers three menu locations:

  • Primary Menu — desktop navigation bar. Supports one level of dropdowns.
  • Footer Menu — horizontal links in the footer bar.
  • Mobile Menu — independent menu for the slide-in mobile panel.

To assign a menu: go to Appearance > Menus, select (or create) a menu, tick the desired location(s) in Menu Settings, and save.

Dropdowns: Add a child item beneath any top-level item to create a dropdown. The theme handles all ARIA attributes automatically via NovaSaaS_Walker_Nav.

Child Theme

Always use a child theme for customizations so your changes survive theme updates.

1. Create the child theme folder

Create /wp-content/themes/novasaas-child/

2. Add style.css

/*
Theme Name:   NovaSaaS Child
Template:     novasaas
Version:      1.0.0
*/

3. Add functions.php

<?php
add_action( 'wp_enqueue_scripts', function () {
    wp_enqueue_style(
        'novasaas-child-style',
        get_stylesheet_uri(),
        array( 'novasaas-style' ),
        wp_get_theme()->get( 'Version' )
    );
} );

Activate the child theme in Appearance > Themes.

RTL Support

WordPress automatically loads rtl.css when the active language is right-to-left (Arabic, Hebrew, Persian, Urdu, etc.).

To test RTL manually, add the following to wp-config.php:

define( 'WPLANG', 'ar' ); // Arabic

Or install a RTL language pack via Settings > General > Site Language.

Translation

All user-facing strings use the novasaas text domain. A POT template is included at languages/novasaas.pot.

Using PoEdit

  1. Open PoEdit and choose Create New Translation.
  2. Open languages/novasaas.pot as the source.
  3. Select your language and translate the strings.
  4. Save as novasaas-{locale}.po (e.g. novasaas-de_DE.po) in the languages/ folder. PoEdit will also generate the .mo binary.

WordPress picks up the translation automatically when the site language matches the locale.

Frequently Asked Questions

How do I set the Home page as the front page?

Go to Settings > Reading. Under Your homepage displays, select A static page. Set Homepage to your "Home" page (the one using the Home — NovaSaaS template).

The AJAX contact form is not working

Ensure class-ajax-handler.php is being loaded (check functions.php). Also check that the nonce field in the form matches the nonce verified in the handler (novasaas_contact_nonce).

How do I add more pricing plans?

Edit the $plans PHP array at the top of page-templates/template-pricing.php (and template-home.php). Each plan is an associative array with keys: name, price_monthly, price_yearly, description, features (array), cta, cta_url, popular.

How do I use a custom font not on Google Fonts?

Enqueue your font in a child theme's functions.php, then override the CSS variable: --novasaas-font-heading: 'Your Font', sans-serif; in Additional CSS.

Can I remove the StreamFlow branding?

Yes. All demo text is pulled from novasaas_get_option() calls, which read from the Customizer. Update the Hero section and other text fields in Appearance > Customize > NovaSaaS Theme.
